Installer un serveur web Apache sur Debian

Apache est un serveur web libre et très répandu. Il permet de publier des sites sur un réseau local ou sur Internet.

Prérequis

Avant de commencer, il faut disposer d'une machine Debian à jour, d'un accès administrateur et d'une connexion réseau.

Installation

Voici la procédure dans l'ordre :

  1. Mettre à jour la liste des paquets.
  2. Installer le paquet apache2.
  3. Vérifier que le service est démarré.
  4. Ouvrir la page http://localhost dans un navigateur.

Attention : n'ouvrez jamais le port 80 vers Internet sans avoir configuré un pare-feu.

Caractéristiques principales

Apache offre notamment :

  • Une configuration modulaire.
  • La gestion de plusieurs sites sur un même serveur
  • Une grande documentation communautaire.
