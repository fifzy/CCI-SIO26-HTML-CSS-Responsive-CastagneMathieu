# Partie 1

`<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Serveurs et services</title>
</head>
<body>
  <h1>Les serveurs</h1>
  <p>Un serveur fournit des services à des clients.</p>
</body>
</html>`

Q1. Si le [4] est absent la page n'affichera pas correctement les accents, le navigateur va mal interpréter les caractères spéciaux

Q2. Le contenu [5] s'affiche dans l'onglet et le contenu de [7] s'affiche en premier titre de la page web

Q3. Le `head` contient les informations sur la page destinées au navigateur et aux moteurs de recherche (titre, encodage,métadonnées...), alors que le `body` contient tout le contenu visible affiché à l’utilisateur

Q4. Le navigateur récupére des fichiers d'une page auprès du serveur (HTTP/HTTPS) et interprete le HTML, le CSS, puis affiche le résultat 

HTML, CSS et JavaScript en une phrase : le HTML structure le contenu de la page, le CSS définit sa mise en forme (couleurs, polices, disposition), et le JavaScript la rend dynamique et interactive.

# Partie 2

Le `h1` porte le sujet principal de la page (les sauvegardes) et reste unique, tandis que le `h2` introduit une sous-partie de ce sujet, ce qui respecte une hiérarchie logique sans sauter de niveau. Une liste non ordonnée `ul` est utilisée car les trois types de sauvegarde sont des éléments de même niveau, sans ordre ni étapes à suivre : une liste ordonnée `ol` ne serait justifiée que si l’ordre avait un sens.
