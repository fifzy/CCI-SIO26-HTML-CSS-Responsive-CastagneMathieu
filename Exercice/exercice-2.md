# Exercice 2 : Créer un document HTML5

1. **Type de document :** pour définir le type de document en HTML5, j'ai écrit `<!DOCTYPE html>` à la première ligne, pour faire passer le navigateur en mode standard.
2. **Langue :** pour la langue du fichier, j'ai écrit `<html lang="fr">` ; cela sert à connaître la langue utilisée et permet aux outils d'accessibilité d'être cohérents dans la diction de la page.
3. **Encodage :** pour l'encodage de la page, j'ai utilisé `<meta charset="UTF-8">` pour que le navigateur affiche correctement les accents.
4. **Titre de l'onglet :** j'ai intégré une balise `<head>` ; dans cette balise, en dessous de `<meta charset="UTF-8">`, j'ai ajouté une balise `<title></title>` en mettant mon titre entre ces balises, pour identifier la page dans l'onglet, les favoris ect...
5. **Titre visible :** ensuite, j'ai ajouté une balise `<body>` dans laquelle j'ai intégré le titre de la page avec `<h1></h1>`, cette balise permet d'afficher le titre dans la page.
6. **Paragraphe :** finalement, juste en dessous, j'ai ajouté `<p></p>` pour écrire mon texte de présentation.
7. **Aucun CSS :** a page ne contient ni balise `<style>`, ni attribut `style`, ni lien vers une feuille de style (`<link rel="stylesheet">`). Elle s’affiche donc avec les styles par défaut du navigateur.

À noter : dans la deuxième phrase, j'ai utilisé `&amp;` pour éviter un conflit et que le navigateur le confonde avec une entité
